A Nim library to render tables interactively, `tableview`, allows tools to offer
a smooth experience while browsing data.
It supports search, sorting by column, hiding columns and truncating long cells.

### To install it

```nim
nimble install tableview
```

### CLI demo

The library installs a tiny CLI tool called `tableview`.
